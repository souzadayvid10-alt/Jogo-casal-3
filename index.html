Duas pessoas. Duas versões da verdade. Uma mansão que não quer deixar ninguém sair.

ou entrar com um código

Cada jogador usa seu próprio celular. Mantenham a página aberta e conversem por ligação ou WhatsApp: as pistas são diferentes em cada tela.

O jogo usa conexão direta entre navegadores via PeerJS. É necessário acesso à internet para estabelecer a conexão.
